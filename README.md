# 📊 ReviewPulse AI

**ReviewPulse AI** is an intelligent sentiment analysis and customer feedback dashboard built with Python and Streamlit. It helps businesses process, visualize, and extract actionable insights from customer reviews and e-commerce data.

---

## 🌟 Key Features

* **💬 Customer Review Sentiment Analysis**: Automatically analyzes text polarity and categorizes feedback into positive, neutral, or negative sentiments.
* **📈 Interactive Visualizations**: Features clean charts and metrics built using Pandas, Plotly, and Matplotlib to track customer satisfaction trends.
* **🌐 Sleek Dashboard Interface**: Designed with Streamlit for a fast, responsive, and user-friendly experience.

---

## 🛠️ Tech Stack

* **Frontend & UI**: Streamlit
* **Data Processing**: Pandas
* **Sentiment Engine**: TextBlob
* **Data Visualization**: Plotly, Matplotlib
